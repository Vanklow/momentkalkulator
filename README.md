# Momentkalkulator

This project provides a simple calculator for bolt joint preload and torque. The GUI is implemented with `tkinter` and relies on a small set of material and thread databases.

## Usage

1. Install Python 3.x with Tk support.
2. Run the GUI application:

```bash
python bolt_moment_gui.py
```

3. Select thread type, sizes and material properties or enter your own values, then click **Calculate** to see recommended clamp forces and torque ranges.

The CLI example in `main.py` demonstrates how the calculation functions can be used programmatically.
